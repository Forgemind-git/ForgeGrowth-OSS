## Getting listed

Every merged pull request earns a place here. If you have contributed and your name is missing, or
listed in a way you would rather it were not — a different name, a handle instead of a name, or no
entry at all — open a pull request against this file or email the address above. It will be changed
without argument.

Vulnerability reports are credited too, in the release notes and here, unless the reporter asks
otherwise. See [`SECURITY.md`](./SECURITY.md).
